# extractions — provenance records

Study notes taken while designing loom, one file per source that was read. They are historical: a
note here may describe an approach loom later dropped, and none of them is a contract.

Each file quotes excerpts from its source under that source's own license. Those quotes are
evidence for the notes, not a distribution of the upstream project. What loom actually ships from
another project is recorded in `THIRD_PARTY_NOTICES.md`, with the full license text of each source
under `third_party/LICENSES/`; design influences that contributed no code are in `CREDITS.md`.
Where a note and those two files disagree about what was taken, those two files are correct.
