# docs/archive — internal build records

Kept for provenance. Not maintained, not a guide to using loom, and not a live contract: where any
of these files disagrees with the code, the code wins. The public record of what loom took from
where is `THIRD_PARTY_NOTICES.md` (code, with licenses) and `CREDITS.md` (design influences).

| File | What it is |
|---|---|
| `PLAN-v1.md` | The original user-authored plan. Kept verbatim; it contains facts later found wrong, and every correction lives in `docs/BUILD-SPEC.md` §11 DECISIONS-DELTA. |
| `GATE-1.md` | Skeptic review of the extractions before the build started. |
| `GATE-2.md` | Spec-freeze review of BUILD-SPEC. |
| `BUILD-LOG.md` | Dated record of what landed in each build pass. |
| `LIVEFIRE.md` | Transcript of the live two-user run against a real repository. |
| `extractions/` | Per-source study notes taken while designing loom. See `extractions/README.md`. |
