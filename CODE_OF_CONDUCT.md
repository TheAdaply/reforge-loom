# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](
https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. The
linked text is authoritative; it is referenced rather than copied so that it cannot drift here.

In short: everyone participating in this project — issues, pull requests, discussions — is expected
to treat other people with respect. Harassment, personal attacks, and demeaning or exclusionary
behaviour are not acceptable, in public or in private.

## Reporting

Report a problem to the maintainers through this repository's GitHub Security Advisories, or
privately to the maintainer listed in `pyproject.toml`. Reports are handled confidentially. The
maintainers will respond, and may warn, temporarily block, or permanently ban anyone whose
behaviour they judge to violate this code.
